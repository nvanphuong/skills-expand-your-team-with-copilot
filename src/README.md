# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities through Facebook, WhatsApp, email, or a copied link without logging in

Shared links highlight the selected activity. If automatic copying is unavailable,
the link is shown for manual copying. Sharing includes only the activity name and
link, not participant details. No social media scripts are loaded.
